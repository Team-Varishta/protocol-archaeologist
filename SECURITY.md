# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a top priority for Team Varishta. 

If you discover a security vulnerability within Protocol Archaeologist, please report it privately:
1. Do **not** open a public issue on GitHub.
2. Contact the development team directly via the hackathon Slack or email the team lead.
3. Include detailed steps to reproduce the vulnerability.

We will acknowledge receipt within 24 hours and coordinate a patch.
